# RADIKAL TECH CLUB - Dashboard Financiero 2026

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://radikal-tech-club.streamlit.app)

## Descripcion

Dashboard financiero interactivo para **RADIKAL TECH CLUB**, plataforma One-Stop Shop de IA para comercializacion y mercadeo dirigida a MiPyMEs (Micro, Pequenas y Medianas Empresas) en Latinoamerica.

## Caracteristicas

- **Informe Financiero**: Visualizacion de inversion y gastos por jurisdiccion
- **Modelo de Ingresos**: Editor interactivo de servicios (Launch, Sell, Optimize)
- **Presupuesto 2026**: Analisis de ingresos vs gastos con proyecciones
- **Escenarios de Capital**: Simulacion de necesidades de financiamiento
- **Equity Agreement**: Detalle del vesting de JP Pineda (CEO)

## Instalacion Local

```bash
# Clonar repositorio
git clone https://github.com/YOUR_USERNAME/radikal-tech-club.git
cd radikal-tech-club

# Crear entorno virtual
python -m venv venv
source venv/bin/activate  # Linux/Mac
# o: venv\Scripts\activate  # Windows

# Instalar dependencias
pip install -r requirements.txt

# Ejecutar
streamlit run streamlit_app.py
```

## Deploy en Streamlit Cloud

1. Fork este repositorio
2. Ve a [share.streamlit.io](https://share.streamlit.io)
3. Conecta tu cuenta de GitHub
4. Selecciona el repositorio y `streamlit_app.py`
5. Click en Deploy
